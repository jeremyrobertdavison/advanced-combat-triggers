# Changelog

All notable changes to Advanced Combat Triggers will be documented in this file.

## 1.0.0 - 2026-09-17

### Added

- Player-perspective hostile visibility detection.
- First-sighting trigger with cross-player duplicate suppression.
- Re-arming after all players lose visibility of the hostile.
- Visible Friendly/Neutral-to-Hostile disposition trigger.
- Default pause-and-prompt behavior for visible disposition changes.
- GM prompt with Start Combat, Pause Only, and Ignore actions.
- Automatic combat encounter creation/start.
- Optional addition of active player-owned scene tokens to combat.
- World settings and debug logging.
- GitHub Release packaging workflow.
